# The Ethical Spine

Project Parallax should be built around discernment.

## Guiding North Star

> Build tools that help people see patterns without surrendering their discernment.

## Development Principles

### 1. No False Certainty

Use language like:

- patterns suggest
- historically associated with
- one possible lens
- traditional interpretation
- current evidence is limited
- this is symbolic, not deterministic
- this may be worth reflecting on
- the sources suggest
- the pattern appears in

Avoid language like:

- this will happen
- the universe guarantees
- you are destined to
- this proves
- the only truth is
- the system knows better than you

### 2. No Guru Positioning

The brand voice should feel like:

- researcher
- synthesizer
- explorer
- curator
- facilitator
- architect

Not:

- prophet
- savior
- final authority
- spiritual master
- all-knowing oracle

### 3. Make the Process Visible

Let people see:

- experiments
- research notes
- course explorations
- behind-the-scenes synthesis
- what is being studied this week
- how the framework is being built
- what each lens reveals and what it does not

This supports a transparent, Pluto-in-Aquarius-aligned brand ethic.

### 4. Build the Smallest Sacred Container First

Do not launch the full temple first.

Launch the first room.

Examples:

- one Prismarium course circle
- one Kairos planner cohort
- one Chronos weekly astrology weather report
- one Project Parallax newsletter
- one “Similar Skies” research series
- one public research note per week

- grounded
- intelligent
- reverent
- curious
- transparent
- poetic but clear
- mystical but not vague
- technological but not cold
- spiritual but not dogmatic

## Voice Should Not Feel

- guru-like
- fear-based
- overly certain
- overly academic
- fluffy
- manipulative
- hyper-commercial
- “AI will solve your soul” coded
