# 3) Color usage rules

## Ratio guidelines

### For Project Parallax

- 60% dark neutrals
- 20% white / light text
- 20% spectral accents

### For each product page

- 70% dark neutrals / product-specific dark surface
- 20% product primary + secondary
- 10% accent / glow / highlight

## Important rule

**Do not overuse full-spectrum gradients inside product experiences.**

Use:

- **multicolor** for **Project Parallax**
- **monochromatic family** for **product-specific experiences**

That keeps the system clean.

# 7) Art direction for logo system

You asked how each product logo should differ while still feeling unified.

This is the most important design-system move.

---

## A. Shared visual DNA across all logos

All four logos should share the same family language.

### Shared rules

- geometric construction
- sacred geometry influence
- triangular logic
- monoline foundation
- centered symmetry
- luminous/digital feel
- scalable flat version + glow version
- works on dark background first

### Technical style guidance

- Build all icons on a consistent geometric grid
- Use consistent stroke weight across the family
- Keep corners and intersections intentional and clean
- Prioritize strong silhouette
- Ensure each icon works:
    - in full glow
    - in flat single color
    - in monochrome
    - at favicon/app-icon scale

---

## B. Project Parallax logo art direction

### Role

The master symbol should feel like the **union point** of the ecosystem.

### Form language

- interlocking triangles
- multi-layer geometry
- prismatic convergence
- slight star quality
- feeling of portal / convergence / refraction

### Visual meaning

This should represent:

- multiple perspectives
- convergence
- parallax
- synthesis across difference

### Color treatment

- use the triadic gradient:
    - violet
    - cyan
    - gold

### Notes

This should be the only mark that confidently uses the full spectral treatment as part of its core identity.

---

## C. Kairos logo art direction

### Role

Kairos should feel:

- personal
- intuitive
- rhythmic
- alive
- moment-sensitive

### Form language

- lighter, more open geometry
- constellation-like triangle
- fewer lines than the other marks
- more negative space
- one emphasized point/star to suggest “the right moment”

### Visual meaning

It should suggest:

- timing
- personal navigation
- insight
- living rhythm
- alignment

### Recommended shape language

- open triangle
- orbital point structure
- constellation geometry
- subtle asymmetry allowed

### Motion behavior

- pulse

- phase alignment

### Color

- violet / lilac only

Prismarium should feel:

- synthetic

- luminous

# 9) Practical design rules

## Do

- Use dark mode as the primary environment
- Use glow sparingly and intentionally
- Give each product a dominant single hue
- Keep shapes geometric and premium
- Make icons clean enough for software/app use
- Maintain strong contrast and legibility
- Build system versions: hero / product card / flat UI / favicon

## Don’t

- Don’t let every product use the full rainbow gradient
- Don’t make the product logos equally dense
- Don’t overload product pages with cosmic effects
- Don’t blur the functional distinction between products
- Don’t rely on glow to define the logo shape
