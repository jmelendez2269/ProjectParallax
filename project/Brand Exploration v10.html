08 · BUTTONS & UI COMPONENTS

Ghost/outline. Always.

No solid fills on primary buttons. All calls-to-action use transparent backgrounds with colored borders — fill only on hover as a glow state.

PRODUCT COLORS
STATES
Design rationale. Ghost buttons let the dark void background breathe through. The neon product colors read as light sources — the border is the glow's edge. Solid fills would kill the luminosity that makes the UI feel like it lives in space. Hover states add a soft box-shadow glow, never a hard fill.
